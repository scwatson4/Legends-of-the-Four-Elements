# Controls Reference

All input currently implemented (classic Army Men RTS / Halo Wars style).

## Mouse

| Input | Action |
|---|---|
| Left-click | select your unit (buildings/enemies aren't selectable) |
| Left-drag | box-select your units |
| Shift + left-click | add/remove a unit from the selection |
| Double left-click a unit | select ALL your units of that type |
| Right-click ground | move order |
| Right-click enemy | attack order |
| Right-click spirit | befriend/tame order (Avatar only — energy bending) |
| Right-click resource node | send selected workers to harvest it |

## Keyboard

| Key | Action |
|---|---|
| **F** then left-click | **attack-move**: advance to the point, engaging everything hostile on the way |
| **Ctrl + 1–9** | assign selection to a control group |
| **1–9** | select that control group |
| **B** | (campaign) place a new command center — found or expand your base |
| **R** | rotate the building ghost while placing |
| **Esc / right-click** | cancel placement, cancel attack-move, skip dialogue |
| **T** | Avatar: cycle bent element (Air → Water → Earth → Fire) |
| **G** | Avatar: Avatar State (10s power surge, 60s cooldown) |
| **F1–F4** | (campaign) summon redeemed Avatars: Air / Water / Earth / Fire |
| **W A S D / arrows** | pan camera |
| **− / =** | zoom out / in *(moved off 1/2 to free the number keys for control groups)* |
| **Shift + A** | toggle map view |
| Space / Enter / click | advance dialogue |

## Tower elements (auto-fire, every 4th shot is a special)

| Tower | Each shot | Special (4th shot) |
|---|---|---|
| Fire (Flame Turret) | burn damage over time | **lightning strike** — 3× damage |
| Air (Wind Cannon Pagoda) | knocks the target backwards | **tornado** — damages & scatters the whole pack |
| Water (Ice Spike Tower) | ice crystal slows the target | **wave** — hits and slows every nearby enemy |
| Earth (Rock Launcher) | boulder with splash damage | **massive boulder** — 2× damage, full splash |
